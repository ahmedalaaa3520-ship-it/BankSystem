# Bank System

A console-based Bank Management System developed in C++.

The project allows managing clients, users, banking transactions, and
user permissions using file handling.

## Features

### Client Management
- Add New Client
- Delete Client
- Update Client Information
- Find Client
- List All Clients

### User Management
- Add New User
- Delete User
- Update User Information
- Find User
- List All Users

### Authentication & Permissions
- Login using username and password
- Permission-based access control
- Different permissions for different users
- Full access permission
- Access denied handling
- Logout functionality

### Banking Transactions
- Deposit Money
- Withdraw Money
- Show Total Balance

### Data Management
- Save Client Data Using File Handling
- Save User Data Using File Handling
- Load Data From Files
- Search and Update Records

## Technologies Used

- C++
- File Handling
- Structures
- Enums
- Vectors
- Functions
- String Manipulation
- Bitwise Operators

## About

This project was built as part of the Problem Solving Level 3 course
to practice C++ programming and problem-solving skills through a
console-based Bank Management System.
